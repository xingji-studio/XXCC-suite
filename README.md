# XXCC 编译器（基于Clang）

# 编译：

```
make win（对应平台名）
```
## Windows下编译
### Cygwin
1. **下载[`Cygwin`](https://cygwin.com/)**
2. **准备以下软件包: `make`,`gcc-core`,`gcc-g++`,`binutils`,`autoconf`,`automake`,`libtool`,`patch`,`perl`**
3. **打开`Cygwin Terminal`**
4. **执行以下命令：**
```bash
make win
```
> **或者直接执行`make`也可以**
